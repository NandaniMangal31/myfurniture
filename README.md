# myfurniture

MyFurniture is a beginner-friendly static e-commerce website built using HTML, CSS, and JavaScript. This project simulates an online furniture shopping experience with a visually appealing layout, product listings, and basic interactivity.

🌟 Features:

🖼️ Clean and responsive homepage layout

🛋️ Product showcase with furniture categories

🔍 Basic product search/filter functionality (if implemented)

📦 "Add to Cart" and quantity selection buttons (visual only, no backend)

🎨 Modern and user-friendly design using HTML5 and CSS3

💡 Tech Stack:

HTML5 – Structure and semantic layout

CSS3 – Styling and responsiveness

JavaScript – Interactivity (like buttons or simple animations)

📌 Folder Structure:

index.html – Main landing page

style.css – All design and styling

/images – Product and background visuals
